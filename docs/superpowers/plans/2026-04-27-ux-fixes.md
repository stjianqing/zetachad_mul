# UX Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three UX bugs in zetachad_mul: (1) drill input requires Enter to advance, (2) timer expiry leaves the user stuck on the last question, (3) logout link does nothing visible.

**Architecture:** Three surgical changes. Server adds `expected_digits` to the question payload so the client can auto-submit when the input length matches. Client replaces the form-submit listener with an input listener, fires a self-submit when the timer hits 0, and rewrites the logout handler with visible feedback and resilient navigation.

**Tech Stack:** Node.js 22 + Fastify 5 (server), vanilla ESM JavaScript (client), `node:test` + `assert/strict` (tests).

**Spec:** `docs/superpowers/specs/2026-04-27-ux-fixes-design.md` (commit `def38a1`).

- [ ] **Step 3: Implement `expectedDigits` in generator**

In `server/src/game/generator.js`, modify each `return` statement inside the `switch` in `generate()` to include `expectedDigits`. The simplest approach: compute it once at the end. Replace the `switch (op) { ... }` block (lines 25-55) so that each `case` builds a `result` object instead of returning, and the function returns `{ ...result, expectedDigits: String(result.answer).length }` at the bottom.

Final shape of `generate()`:

```javascript
export function generate(config, rng) {
  const enabled = Object.entries(config.ops)
    .filter(([, v]) => v && v.enabled)
    .map(([k]) => k);
  if (enabled.length === 0) throw new Error('no ops enabled');

  const op = enabled[intInRange(rng, 0, enabled.length - 1)];

  let result;
  switch (op) {
    case 'add': {
      const { min, max } = config.ops.add;
      const a = intInRange(rng, min, max);
      const b = intInRange(rng, min, max);
      result = { op, a, b, answer: a + b, prompt: `${a} + ${b}` };
      break;
    }
    case 'sub': {
      const { min, max } = config.ops.sub;
      let a = intInRange(rng, min, max);
      let b = intInRange(rng, min, max);
      if (a < b) [a, b] = [b, a];
      result = { op, a, b, answer: a - b, prompt: `${a} − ${b}` };
      break;
    }
    case 'mul': {
      const { lhsMin, lhsMax, rhsMin, rhsMax } = config.ops.mul;
      const a = intInRange(rng, lhsMin, lhsMax);
      const b = intInRange(rng, rhsMin, rhsMax);
      result = { op, a, b, answer: a * b, prompt: `${a} × ${b}` };
      break;
    }
    case 'div': {
      const { lhsMin, lhsMax, rhsMin, rhsMax } = config.ops.div;
      const quotient = intInRange(rng, rhsMin, rhsMax);
      const divisor = intInRange(rng, lhsMin, lhsMax);
      const dividend = quotient * divisor;
      result = { op, a: dividend, b: divisor, answer: quotient, prompt: `${dividend} ÷ ${divisor}` };
      break;
    }
    default:
      throw new Error(`unknown op: ${op}`);
  }

  return { ...result, expectedDigits: String(result.answer).length };
}
```

- [ ] **Step 1: Update `tickClock` to fire a finishing answer at expiry**

In `client/js/play.js`, replace `tickClock` (currently lines 43-51) with:

```javascript
function tickClock() {
  if (state.finished) return;
  const elapsed = performance.now() - state.startedAt;
  const remaining = Math.max(0, state.timeLimitMs - elapsed);
  els.timer().textContent = Math.ceil(remaining / 1000);
  els.bar().style.transform = `scaleX(${remaining / state.timeLimitMs})`;
  if (remaining <= 10_000) els.timer().classList.add('low');
  if (remaining > 0) {
    requestAnimationFrame(tickClock);
  } else if (!state.timerExpired) {
    state.timerExpired = true;
    finalizeOnTimeout();
  }
}

async function finalizeOnTimeout() {
  let r;
  try { r = await api.answer(state.sessionId, ''); }
  catch (ex) {
    // If the server is unreachable, still close the run with the last known score so the user isn't stuck.
    finish(state.finalScore);
    return;
  }
  if (r && r.time_up) finish(r.final_score);
  else finish(state.finalScore);
}
```

Note: `state.finalScore` defaults to 0 and is only set inside `finish()`. For the unreachable-server fallback, that means the user sees 0 — acceptable because the alternative is staying stuck forever. To preserve a more accurate fallback, also update `submitAnswer()` to track the running score in state. Add this line in `submitAnswer()` right after `els.score().textContent = r.score;`:

```javascript
state.finalScore = r.score;
```

- [ ] **Step 1: Rewrite the logout handler**

In `client/js/landing.js`, replace `renderUserArea` (currently lines 28-40) with:

```javascript
function renderUserArea(user) {
  const el = document.getElementById('user-area');
  if (user) {
    el.innerHTML = `<span class="user-chip">${user.username} <a href="#" id="logout">log out</a></span>`;
    document.getElementById('logout').addEventListener('click', async (e) => {
      e.preventDefault();
      const link = e.currentTarget;
      if (link.dataset.busy === '1') return;
      link.dataset.busy = '1';
      const original = link.textContent;
      link.textContent = 'logging out…';
      link.style.pointerEvents = 'none';
      try {
        await api.logout();
      } catch (ex) {
        console.warn('logout request failed; navigating anyway', ex);
      }
      // Hard navigation rather than location.reload() to avoid any cached document state.
      location.href = location.pathname;
    });
  } else {
    el.innerHTML = `<a href="login.html">Log in</a> <a href="register.html">Register</a>`;
  }
}
```

Reasoning for each change:

- `link.dataset.busy` guards against double-click spam.
- `link.textContent = 'logging out…'` gives immediate feedback that the click registered (the original "nothing happens" symptom).
- `pointer-events: none` prevents further clicks during the in-flight request.
- `try/catch` ensures navigation happens even if the request 401s, 500s, or hits a network error.
- `location.href = location.pathname` is a hard navigation to the same page; bypasses any document cache that might have served `reload()` from disk and re-rendered the logged-in state.
